## Table Definitions

### conversation_thread table
**Purpose**: Groups related messages into conversation sessions

```sql
CREATE TABLE conversation_thread (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    CONSTRAINT fk_thread_user
        FOREIGN KEY (user_id) REFERENCES user(id) ON DELETE CASCADE
);

CREATE INDEX idx_thread_user_id ON conversation_thread(user_id);
CREATE INDEX idx_thread_updated ON conversation_thread(updated_at DESC);
```

**Constraints**:
- `id`: Primary key, UUID generated by database
- `user_id`: Foreign key to user, CASCADE delete
- `created_at`: Thread creation timestamp
- `updated_at`: Last message timestamp (auto-updated)

### conversation_message table
**Purpose**: Individual messages in a conversation

```sql
CREATE TABLE conversation_message (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    thread_id UUID NOT NULL,
    role VARCHAR(20) NOT NULL CHECK (role IN ('user', 'assistant')),
    content TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),

    CONSTRAINT fk_message_thread
        FOREIGN KEY (thread_id) REFERENCES conversation_thread(id) ON DELETE CASCADE
);

CREATE INDEX idx_message_thread_id ON conversation_message(thread_id);
CREATE INDEX idx_message_created ON conversation_message(created_at ASC);
```

**Constraints**:
- `id`: Primary key, UUID
- `thread_id`: Foreign key to conversation_thread, CASCADE delete
- `role`: ENUM('user', 'assistant')
- `content`: Message text (no length limit)
- `created_at`: Message timestamp

## SQLModel Definitions (Python)

### ConversationThread Model
```python
from sqlmodel import SQLModel, Field, Relationship
from datetime import datetime
from typing import List, Optional
import uuid
from enum import Enum

class MessageRole(str, Enum):
    USER = "user"
    ASSISTANT = "assistant"

class ConversationThread(SQLModel, table=True):
    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    user_id: uuid.UUID = Field(foreign_key="user.id", ondelete="CASCADE")
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)

    # Relationships
    messages: List["ConversationMessage"] = Relationship(
        back_populates="thread",
        sa_relationship_kwargs={"cascade": "delete", "order_by": "ConversationMessage.created_at"}
    )
```

### ConversationMessage Model
```python
class ConversationMessage(SQLModel, table=True):
    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    thread_id: uuid.UUID = Field(foreign_key="conversation_thread.id", ondelete="CASCADE")
    role: MessageRole = Field(...)
    content: str = Field(...)
    created_at: datetime = Field(default_factory=datetime.utcnow)

    # Relationships
    thread: ConversationThread = Relationship(back_populates="messages")
```

## Context Retrieval

### Loading Conversation History
```python
def load_thread_messages(db: Session, thread_id: uuid.UUID) -> List[dict]:
    """Load conversation history for agent context."""
    messages = db.query(ConversationMessage).filter(
        ConversationMessage.thread_id == thread_id
    ).order_by(
        ConversationMessage.created_at.asc()
    ).all()

    return [
        {"role": m.role.value, "content": m.content}
        for m in messages
    ]
```

### Context Window Management
```python
MAX_MESSAGES = 50  # Keep last 50 messages
MAX_TOKENS = 8000  # Approximate token limit

def get_context_for_agent(db: Session, thread_id: uuid.UUID) -> List[dict]:
    """Get conversation context, truncated to fit token limits."""
    messages = load_thread_messages(db, thread_id)

    # Truncate if too many messages
    if len(messages) > MAX_MESSAGES:
        messages = messages[-MAX_MESSAGES:]

    # Calculate approximate tokens
    total_chars = sum(len(m["content"]) for m in messages)
    if total_chars > MAX_TOKENS * 4:  # Rough character-to-token ratio
        # Keep only recent messages
        messages = messages[-20:]

    return messages
```

## Data Retention

### Retention Policy
| Data Type | Retention | Action |
|-----------|-----------|--------|
| Conversation threads | 1 year | Soft delete after 1 year |
| Conversation messages | Same as thread | CASCADE delete |
| Empty threads | 30 days | Auto-delete if no messages |

### Cleanup Query
```sql
-- Delete threads older than 1 year
DELETE FROM conversation_thread
WHERE updated_at < NOW() - INTERVAL '1 year';

-- Delete empty threads older than 30 days
DELETE FROM conversation_thread
WHERE created_at < NOW() - INTERVAL '30 days'
AND NOT EXISTS (
    SELECT 1 FROM conversation_message
    WHERE conversation_message.thread_id = conversation_thread.id
);
```
